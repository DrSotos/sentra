# 🌿 SENTRA API — EU Horizon Europe Research Prototype

Welcome to the **SENTRA** (Smart Environmental Network for Territorial Resilience Analytics) backend engine hosted on Hugging Face Spaces.

### 🚀 Key Features
- **Real-Time Telemetry:** Ingestion from European Copernicus (CAMS) & Open-Meteo across European metropolitan zones.
- **Explainable AI (XAI):** Isolation Forest anomaly detection with statistical baseline deviation and natural language rationales.
- **What-If Policy Simulator:** Dynamic decision support simulating Low Emission Zones, Urban Green Canopies, and EV transit fleet adoption.
- **Citizen Science Advisory:** Real-time localized health, outdoor sports, and indoor ventilation advisories based on European AQI.
- **Open Science & FAIR Data:** GeoJSON (INSPIRE compliant) and CSV timeseries endpoints.
